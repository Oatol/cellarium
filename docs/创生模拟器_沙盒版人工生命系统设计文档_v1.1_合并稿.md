文档版本 v1.0。本项目是一款基于 Godot 4.3+ 的 GPU 加速 2D 人工生命沙盒模拟器，聚焦多细胞生物发育、开放式进化与自由环境干预。设计参考《创生协议》的界面与玩法设定、Alien（chrxh/alien）的粒子物理与进化框架、Substrate 的化学场机制，以及 Cell Lab 的基因编辑逻辑。

全文从核心定位出发，依次说明模拟规则、界面规范、工具系统、生物与基因体系、进化机制，最终落到 Godot 技术实现、开发节奏与 AI Agent 接口。

## 1. 项目概述

### 1.1 核心定位

本项目是一款以「木卫二冰下海洋实验室」为世界观背景的人工生命模拟沙盒。玩家通过基因编辑器设计单细胞与多细胞生物，投放到可交互的培养皿环境中，观察其在自然选择下的生存、繁殖、突变与生态涌现。全程无强制关卡与目标，支持全维度环境干预与演化观测，面向人工生命爱好者、演化生物学学习者与创意创作者。

### 1.2 设计理念

无适应度进化：不预设任何评分与奖励，物种存续完全由环境资源、种间竞争与物理规则自然筛选。

发育式形态：生物形态由基因组编码的发育指令生成，突变作用于发育过程，支持真正的开放式形态演化。

闭环能量系统：能量与物质严格守恒，从环境输入到生物传递再到分解回归，形成完整生态循环。

高自由度干预：提供从微观细胞到宏观环境的全套编辑工具，玩家可在「观察者」与「干预者」之间自由切换。

## 2. 核心模拟设定

### 2.1 世界观背景

模拟载体为「欧罗巴站」的冰下海洋样本培养皿，研究目标是在可控环境中复现生命起源与演化过程，观察不同环境压力下的生态系统涌现。所有模拟在圆形培养皿中进行，支持从宏观种群到显微细胞的多级缩放观测。

### 2.2 环境维度体系

培养皿内存在 5 类可动态变化的环境场，全部支持空间梯度与实时编辑：

温度场：单位 ℃，影响生物代谢速率与存活阈值，热泉口为天然高温源（基准 22℃）。

营养场：溶解态有机物，是异养生物的能量来源，可通过投放补充。

**营养实体（v0.14.0 版本化追加）**：在五通道场之外，增加一层只读派生/可视化的「食物实体池」，借鉴 Cell Lab `Food[]` 的定长对象池方法（一次性分配、池尾交换回收、质量随 tick 衰减、涂层比例字段）。实体由营养场源项的确定型投放位置派生，只承载"可见食物颗粒 + 诊断位置"，能量真相仍是营养场；实体不写入能量结算、不进入确定性 hash、不修改五通道 schema。这样既保留 v1.0 的场为唯一能量真相，又提供 Cell Lab 式可见食物颗粒。若未来要让食物实体参与摄能，须再修订本条并从场源项迁移能量真相。

氧气场：溶解氧浓度，调控生物呼吸效率与毒性阈值。

光照场：随深度衰减，是光合生产者的能量输入源。

化学信号场：生物分泌的信息素，用于种内通讯、引诱与警戒。

### 2.3 呼吸机制

基因组可选择三种呼吸方式，直接决定能量效率与生存限制。

| 呼吸方式 | 能量效率 | 生存限制 |
| --- | --- | --- |
| 厌氧型 | 无需氧气即可代谢。 | 环境氧气浓度超过 8% 时会中毒损伤。 |
| 好氧型 | 氧气充足时，等量食物可获得约 3 倍能量。 | 缺氧时代谢效率降至 50%。 |
| 兼性型 | 有氧无氧均可存活，效率与耐受度均弱于专精型。 | 基因预算额外占用 2 点。 |

### 2.4 能量与物质循环

输入端：光照驱动光合生物固定能量，热泉口释放基础营养。

传递端：采集者取食生产者，捕食者取食采集者，能量沿食物链逐级传递。

输出端：生物代谢持续消耗能量，死亡后躯体分解为营养回归环境。

守恒规则：系统总能量与物质严格守恒，无凭空生成，干预工具仅做空间转移。

### 3.3.1 显微视野与观察控制（v1.1 增补 · 借鉴 Cell Lab / Macro）

> 依据：`analysis/CellLab_界面与实验条件_词条证据.md` §3。Macro 独有 `lens_*` / `micro_camera_*` 系列词条，官方版只有基础缩放。只借鉴交互结构，不复制 UI 资源与文案。

在 §3.3「视图层级：宏观 / 群体 / 显微」基础上，显微档补充以下观察控制：

| 能力 | 词条依据 | 本项目的约束 |
| --- | --- | --- |
| 镜头滤镜切换 | `lens_filter_default` / `eyepiece` / `fov` / `fused` / `sepia` | 只切换渲染后处理与配色，不改物理、不改 tick、不写模拟状态 |

| 视野锁定 | `setting_preview_lock` | 锁定后禁止平移 / 旋转 / 缩放，参数编辑与时间轴仍可用；用于精细对照 |
| 图层图例 | `distribution_legend_*` 及 Macro 更新日志中的「固定锚点 / 不占位 / 不裁切」 | 图例为浮层，锚定在视图角落，不参与布局计算，不挤压培养皿主视图 |
| 缩略图捕获 | `micro_camera_plate` / `organism` / `genome_saved` | 培养皿、生物体、基因组三类缩略图，作为 §7.3 书签与物种库封面；捕获的是渲染帧，不影响模拟状态 |

补充约束：

1. 所有控件仍需语义化 ID（延续 §3 开头「支持 AI Agent 精准定位交互」的要求）。
2. 显微视野显示的「单个生物的细胞细节与内部结构」在 v1.1 后应按 §5.3.1–§5.3.5 展示细胞类型、连接与细胞内物质流向，而不是单细胞轮廓。

> 依据：证据文档 §1.1。官方与 Macro 的 `modes` 数组完全一致：冻结 / 观察 / 培养 / 慢速观察（Freeze / Observe / Incubate / Slow observe）；Macro 以 `temp_menu_title`「基底温度」作为叙事包装。

| 档位 | 对应 §4.3 能力 | 语义 | 是否可编辑 |

#### 4.3.2 无渲染快进（v1.1 增补 · 借鉴 Macro 过夜培养）

> 依据：证据文档 §1.2。Macro 独有 `overnight_incubation`（过夜培养）、`overnight_renderless_status`（只显示培养皿时间与细胞数）、`overnight_return_to_plate`（返回培养皿），以及 `log_intervals`（none / 12m / 1h / 5h / 25h / 125h / 625h）与统计日志、保持唤醒设置。「renderless」为键名推断，未经运行期验证。

新增一种独立于倍速的快进模式：

1. 关闭渲染、粒子特效、热力图与统计面板刷新，**只运行完整 tick 内核**；无渲染不等于跳过任何计算阶段，固定 1/60 tick、阶段顺序与派生 RNG 必须与观察档完全一致。
2. 状态栏只暴露「培养皿时间 / 细胞数 / 已完成 tick 数」，并提供「返回培养皿」随时中断。
3. 目标时长按模拟时间分档（建议沿用 1h / 5h / 25h / 125h / 625h），支持自定义；**必须分批执行**，每批结束写一次检查点与统计采样，避免长时间满载。
4. 与 §7.3 存档回溯联动：快进开始时自动建立一个书签，检查点可单独回溯，支持从任意检查点分叉。
5. 结束时生成「快进摘要」：起止模拟时间、执行 tick 数、种群峰值、出生 / 死亡 / 灭绝事件数、快照路径。
6. 采样间隔可配置（`log_intervals` 语义），统计日志只写磁盘，不进 tick 计算。

风险约束：本机长时间满载会过热，快进必须「分批 + 可中断 + 检查点」，禁止一次性跑满；单批时长上限由实现层给出。

### 5.2 基因组编码规则

基因组采用「线性位点 + 全局性状」双层结构。

位点层：共 8 个基因位点，每个位点可装配一种功能细胞，对应 DNA 螺旋上的一段碱基对。

全局性状层：8 项可滑动调节的全局属性，影响所有细胞的基础参数。

速度：提升移动速度，同步提升游动能耗。

感知：扩大感知范围，增加能耗且更容易被捕食者发现。

外壳：提升物理抗性，增加体重、降低移动速度。

攻击：提升攻击伤害，提高器官维持能耗。

繁殖：缩短分裂间隔，降低新生个体初始能量。

代谢：降低基础能量消耗，延长饥饿存活时间，提高分裂能量门槛。

神经：增加行为规则卡槽数量，提升神经系统复杂度，提高能耗。

耐温：扩大适宜温度范围，维持成本随范围提升。

### 5.3 多细胞发育机制

起始：单个受精卵细胞，携带完整基因组。

分裂分化：按发育指令依次分裂，子细胞按预设方向排列并分化为对应功能细胞。

连接建立：相邻细胞间生成弹性连接，同时建立神经信号通路。

**v0.15.0 版本化追加（基因驱动发育，模仿 Cell Lab）**：新增可切换的「基因模式」（`Genome.flags` 位 1），置位后不再使用指令序列——
- **分裂质量**（对应 Cell Lab `Gene.b`）是细胞能量阈值，达到即分裂；这解释了 v0.14.x 中「能量 87 仍不分裂」：旧模式被 `dev_program` 发育状态门控，且阈值写死在管理器里。
- **分裂即分化**：子代 1–4 类型对应 `Gene.i/j` 分化树子槽，按分裂次数依次分配，不再需要 `DIFFERENTIATE` 指令。
- **连接由黏附素决定**：勾选「生成黏附素」即亲子自动连接，`LINK` 指令已从新基因组与编辑器中移除（仅为旧存档保留解码兼容）。
- 分裂质量比、子代角度、最大分裂次数分别对应 `Gene.c`、分裂角、`Gene.b` 之外的子代数量约束。
- 清零时完全保持 v0.14.x 指令模式；基因参数不进 GNP1 冻结二进制，随存档 schema v2 版本化保存，并显式混入基因组 hash。

**v0.17.0 版本化追加（多模式基因组与连接传递）**：用户提供的 Cell Lab Macro 基因组编辑截图显示：一个基因组通过模式列表切换，当前模式独立保存细胞类型、黏附素、两个子代模式与保留黏附素/镜像/角度、分裂质量与质量比、营养优先级、RGB、黏附强度/长度/拉伸、细胞骨架、细胞大小、连接上下限、特殊控制；上方发育预览可点击细胞跳到对应模式。项目据此把基因模式从「一套顶层字段」升级为「多个模式槽」，每个模式只定义**两个子代**——分裂后母细胞索引作为子代 1、新细胞为子代 2，二者分别进入所选模式并采用该模式的类型/表型/阈值/传递率。

- `Genome.modes: Array[Dictionary]` 是模式真相源；每个模式含 `name / cell_type / make_glue / stay_alive / initial / child1_type / child2_type / child1_mode / child2_mode / child1_glue / child2_glue / child1_mirror / child2_mirror / child1_angle / child2_angle / division_mass / invert_split_mass / split_ratio / max_divisions / split_angle / split_angle2 / ratio / ratio2 / nutrition_priority / transfer_rate / cell_stiffness / cell_size / max_connections / min_connections / color_r|g|b / adhesion_strength / adhesion_length / adhesion_stretch`。其中只有已在本项目落地的字段参与运行时；Macro 的 40 Gene 槽、行为总线全索引与未逐行证实的特殊控件不复制、不臆造语义。
- `CellArray` 增加 `cell_mode` / `cell_mode_depth`，逐细胞记录所属模式与该模式已分裂层数。模式切换时层数归零，同模式连续分裂才递增；顶层 `max_divisions` 仍限制个体总细胞数。
- 连接传递率由所属模式的 `transfer_rate` 派生（默认 0.12，0 关闭）。`CellMetabolism` 的守恒公式不变；此前生态报告转出/转入恒为 0 的根因是调用端 `default_transfer_rate = 0.0`，不是诊断显示。旧 `flags` 清零、或基因模式但 `modes` 为空的旧基因组仍使用旧传递率 0，回放/确定性不受影响。
- `modes` 不进 GNP1 冻结二进制；只走 `CommandBus` 的 `genome_gene` payload 与存档 `schema_version=4`（1–3 可恢复，缺字段填 0/空），并只在 `modes` 非空时混入 hash。默认演示体改为 5 模式 3 次分裂 → 4 细胞/3 连接。
- 细胞编辑 UI 增加模式列表（新增/删除/切换/改名），原 Macro 字段改为编辑当前模式；发育预览派生每个细胞的模式索引，点击细胞发出模式跳转信号，编辑器接收后切到对应模式。

**v0.18.0 版本化追加（个体规模上限修订、连接数抑制分裂、端粒）**：Cell Lab 静态证据未发现显式「单个个体最多 N 个细胞」字段；其规模由全局 `Cell[]` 对象池、每细胞连接上限、`P <= Gene.u[9]` 的分裂抑制与端粒共同约束。本项目据此不再把「每个个体最多 8 个细胞」当硬基线，改为：
- `Genome.max_cells_per_organism`：个体细胞数上限，`-1` 表示无限；非负值才钳制个体规模。旧命令/schema 缺该字段时回退为 `max_divisions + 1`，保持 v0.17 及更早行为；新编辑器草案默认为 `-1`。默认演示体仍显式设为 4，保持 4 细胞/3 连接快照。
- 全局容量保护：`CellArray.max_cell_capacity` 默认 8000，所有 `append_cell()` / 分裂路径在达到全局容量后拒绝新增细胞。它替代旧的 per-organism 8 细胞硬上限，防止无限个体拖垮模拟。
- 逐模式 `link_division_limit`：当前细胞连接数达到该值即抑制分裂；`-1` 表示不抑制。Cell Lab 证据是 `P <= Gene.u[9]`，本项目把「达到上限即停」明确为 `>=`，并在细胞编辑中单独暴露，旧模式缺字段填 `-1` 保持旧行为。
- 逐模式 `telomere`：谱系剩余分裂次数，可选 `-1`（无限）、5、10、20、40、80，对应 Cell Lab `Gene.B[6]`。初始细胞继承当前模式端粒；有限端粒的每次分裂让母、子同时减 1，减到 0 时双方死亡并记「端粒耗尽」死因。端粒按细胞保存，不是个体总细胞数上限。
- 这些字段不进 GNP1 冻结二进制；随 `genome_gene` 命令 payload 与 `schema_version=5`（1–4 可恢复）保存，非空 modes / 基因模式字段显式混入 hash；GNP1 布局、tick 顺序与单帧 12 tick 上限不动。

**v0.19.0 版本化追加（半径-能量低通）**：Cell Lab `CellWorld.f(double)` 已证实半径 `d` 不随能量直接跳变，而是对 `d²` 一阶低通、稳态 `d_target = sqrt(w)/20`（§2）。本项目补齐该机制：逐细胞 `cell_radius_baseline`（基因 `cell_size` 表型）与 `cell_energy_scale`（能量派生因子），有效倍率 = 基线 × 因子，物理碰撞、皿壁投影、渲染与分裂间距共用同一有效倍率。每个模拟 tick 以该细胞模式的 `division_mass` 作参考能量，`target² = clamp(E/E_ref, 0.5², 1²)`，按 `s² ← s² + (target² − s²)·rate·dt` 平滑趋近，因此刚分裂的能量较低子细胞半径较小、随摄能逐渐长大，饥饿则平滑收缩。仅基因模式生效，非基因模式与关闭开关时保持固定表型半径；不写 RNG，GNP1、tick 顺序、单帧 12 tick 上限不动。存档升 `schema_version=6`，旧档按 baseline=旧有效倍率、因子=1.0 回退。视图侧将共享弦 pair key 从字符串改为整数打包，膜轮廓采样点做成可配置（场景实例 48、独立实例默认 64），仅优化渲染开销、不改变任何模拟状态或 hash。

**v0.21.0 版本化追加（分裂倍增、半圆出生形状与发育预览分裂指示器）**：Cell Lab `CellWorld.e(double)` 对每个细胞独立判定分裂、无 per-organism cooldown，同一 tick 所有成熟且能量达标者同时分裂，故细胞链按 1/2/4/8 倍增；出生时母子各沿分裂轴偏 `0.1r`（中心距 `0.2r`），半径保留母半径、分裂施加零力，因两圆高度重叠而渲染成两个贴靠半圆，下一 tick 靠接触排斥弹开。Macro `GenomeEditorFragment` 含 `checkbox_show_split_indicators` 控件。本项目据此：① 分裂调度改为逐细胞 cooldown（`CellArray.cell_division_tick` 进 hash/存档，schema v7，旧档填 -2），实测 1→2→4→8→16→32；② 出生间距改为 `0.2r`、母子各偏 `0.1r` 且半径当帧不变，连接静止长度仍为 `2r`，与 Cell Lab 零力+接触排斥一致；③ `GenomePreview.show_split_indicators` 在发育预览叠加垂直于分裂轴的切面线与母→子方向箭头，纯绘制、不写 CommandBus/field/hash。GNP1 二进制布局、tick 顺序、单帧 12 tick 上限不动。

**v0.16.0 版本化追加（基因模式补齐 Macro 表型字段）**：在基因模式内把原「仅草案展示」的字段落地为可运行参数，仍不进 GNP1 冻结二进制，随存档 `schema_version=3` 保存（1–2 可恢复），经 `CommandBus` 的 `genome_gene` payload 写入并显式混入基因组 hash；flags 清零时全部保持 v0.14.x 行为与 hash。

成熟激活：发育完成后神经网络激活，生物开始自主活动。

再生修复：成体部分细胞受损时，能量充足可按基因组指令再生。

### 5.3.1 个体与细胞的关系

一个生物个体由一个或多个细胞构成，细胞通过弹性连接组成同一个体。个体是谱系追踪、物种判定、种群统计与存档的基本单位；细胞不单独拥有谱系编号，不单独判定物种，不单独计入种群数量。

细胞可以死亡、受损或按发育指令再生；个体在其最后一个细胞消失时判定死亡，并按 §2.4 的规则分解回归环境。细胞之间的连接可因距离超限、主动切断或细胞死亡而解除，解除后相应细胞不再属于该个体的协作范围。

### 5.3.2 细胞类型与分工

每个细胞在发育期由分化指令确定一种功能类型。类型决定它在能量获取、能量消耗、运动、感知、结构支撑与防护等方面的角色；同一个体内的细胞可以是不同类型，因此个体能表现出任何单一细胞都不具备的整体能力。

类型布局由基因组中的发育指令决定，可因突变而改变，不使用预定义形态模板（延续 §1.2「发育式形态」）。

层级区分（避免与既有词条混用）：

| 层级 | v1.0 对应 | 含义 |
| --- | --- | --- |
| 位点装备 | §5.1「16 种功能细胞」、§5.2「8 个基因位点」 | 基因组上的一个可装配槽，属于遗传编码层 |
| 全局加成 | §5.2「8 项全局性状」 | 作用于该个体所有细胞的个体级属性 |
| 细胞类型 | 本条新增 | 发育期分化产生的运行时角色，逐细胞不同 |

### 5.3.3 细胞内能量与物质循环

个体总能量等于其所含细胞能量之和。细胞可沿弹性连接交换能量与物质；交换在成对细胞间**等值反向记账**，采用「先合计、再分配」的结算方式。

§2.4 的守恒规则不变：细胞内交换只改变个体内部的能量构成，不改变个体总能量，也不改变系统总能量；不构成凭空生成，玩家的干预工具仍然只做空间转移。产能型细胞可供养运动、感知与防护型细胞，储能型细胞可作为缓冲，由其他细胞提供的能量支撑个体级行为。

### 5.3.4 协作产生的个体级属性

由相连细胞构成的个体可以产生个体级属性，例如整体形变与定向运动、局部防护、分布式感知。这类属性**仅对同一个体内、经由连接可达的细胞生效，不跨个体生效**：防护型细胞可保护与其相连的细胞免受负面交互；运动型细胞可收缩连接驱动整体形变；感知型细胞的输出可作为其他细胞的决策输入。

个体规模由连接数上限、发育指令预算与可用能量共同约束，不允许无限增殖。连接数达到上限时应抑制继续分裂。

### 5.3.5 不变项与排除项

以下 v1.0 既有规则**完全不变**：§1.2 无适应度进化与发育式形态、§2.4 闭环能量系统与守恒、§5.2 基因组双层结构、§6.1 开放式进化、§6.2 谱系追踪、§7 沙盒自由度、§8.3 数据结构方向。

本次细化明确排除：每细胞独立基因组、人工适应度引导、预定义形态模板、跨个体的细胞合并。借鉴 Cell Lab 时同时排除：40 Gene 槽分化树、95 个突变算子、端粒、受精、病毒基因注入、Macro 扩展的细胞类型与信号通道。上述机制若将来要引入，须按实现文档 §0.5.3 的约定重新修订玩法文档并同步工程实现文档。

### 5.3.6 单细胞个体与发育深度轴（2026-11-15 增补）

> 依据：用户 2026-11-15 决策。问题是「Cell Lab 的单细胞几乎没有独立生存能力，而《创生协议》的单细胞可以独立生活」——差别不在功能清单，而在**分工落在哪一层**：Cell Lab 分工在细胞层且功能独占，《创生协议》分工在细胞器层。本条把两层叠加，兼得单体自治与多细胞协作。

**术语统一（不改 v1.0 原文，只统一后续用词）**

| 层 | 本条用词 | v1.0 对应 | 含义 |
| --- | --- | --- | --- |
| 遗传编码层 | 细胞器（Organelle） | §5.1「16 种功能细胞」 | 鞭毛、纤毛、光合膜、储能颗粒、刺丝囊、记忆片段等，实为细胞内可装配模块 |
| 装配层 | 基因位点 | §5.2「8 个基因位点」 | 该基因组能造哪些细胞器 |
| 个体级加成 | 全局性状 | §5.2「8 项全局性状」 | 作用于该个体所有细胞 |
| 运行时角色 | 表达型（Expression Profile） | P0 §5.3.2「细胞类型」 | 每细胞的细胞器表达权重向量的显示名，**不是枚举常量** |

v1.0 §5.1 的表格与文字逐字保留；后续文档、编辑器与代码统一使用「细胞器 / 表达型」，避免把两层清单当成两套互不相干的数据。

**最小自治核**：每个细胞都具备不可剥夺的基础能力（膜、基础代谢、最低限度的摄能 / 运动 / 感知）。细胞器只**放大能力系数**，不垄断能力开关。因此单细胞个体可以独立存活但表现平庸；多细胞个体靠专精 + §5.3.3 连接内再分配获得超额收益；细胞被切离连接图后是效率下降，而不是立即断供死亡。这也让「主动解体 / 再生修复」具备可观察的中间状态。

**发育深度轴**：`dev_program[]` 中 `DIVIDE` 指令的条数决定 `cell_count`。0 条 = 单细胞个体；1..64 条 = 多细胞个体。单细胞与多细胞是**同一基因组在不同发育深度上的两个实例**，不是两套模拟内核，也不是两种生物类别。`cell_count = 1` 时生命周期状态机直接进入 MATURE，不经过 DEVELOPING 等待。突变可增减 `DIVIDE` 指令，使单细胞 ↔ 多细胞成为可演化的形态过渡（§1.2「突变作用于发育过程」），而不是只改数值。

**表达预算与经济性**：每细胞一份固定表达预算，发育指令在其中分配细胞器表达权重；§5.2 的取舍保留（外壳↑则移动↓），细胞器之间的互斥与协同由实现文档给出。单细胞策略要付**重复装备税**（同一套膜内堆多种细胞器，维护费与体重超线性上升）；多细胞策略省掉重复装备，但新增连接维持成本、连接内传输损耗、发育期脆弱与 §5.3.4 的连接数上限。两种策略的优劣由资源有限、种间捕食、环境梯度与随机灾害自然筛选（§6.1），**绝不引入适应度函数或人工引导**（§1.2）。

**培养基参数（用户决策）**：最小自治核的基础值**不硬编码**，由培养基的营养密度参数导出，作为 `EnvironmentPreset` 的一个只读标量。营养密度高 → 基础值高，单细胞更容易独立存活；营养密度低 → 基础值低，多细胞协作的相对收益上升。该参数是**皿级全局标量**，不是局部营养场；局部场仍只影响摄能速率，不改写基础值。参数必须随存档 / 快照 / 回放序列化，运行时不得临时改写，以守住确定性。

**可塑性接口（用户决策：v1 不实现，但保留接口）**：预留只读的 `DevelopmentContext` 快照（环境场摘要、营养密度、发育深度上限），供未来实现「环境诱导的发育深度可塑性」。v1 的发育深度**完全由 `dev_program[]` 遗传决定**，tick 内禁止读取环境场去增删发育指令；该接口只能被未来的显式版本化特性消费，不得成为第二真相源，也不得进入当前 tick 的写入路径。

### 5.4.1 发育与繁殖的分离（2026-11-15 增补）

> 依据：用户 2026-11-15 拍板的地基条款。v1.0 §5.4 只写了「无性二分裂」，不区分「个体内多一个细胞」与「多一个个体」；若不区分，单细胞个体一分裂就变成两个个体，永远长不成多细胞。

| 指令 / 动作 | 效果 | 身份与谱系 | 能量 |
| --- | --- | --- | --- |
| `DIVIDE`（发育） | 同一个体内 `cell_count += 1` | 不产生新 `org_id`，不新增谱系节点 | 在个体内按 §5.3.3 等值反向记账 |

v1.0 §5.4「能量积累到阈值后自动分裂为两个子代」在本版解释为 `REPRODUCE`。对多细胞个体，`REPRODUCE` 的起点是一个新的受精卵细胞（§5.3 起始），由基因组发育程序重建个体，**不是把母体细胞对半切开**。

## 6. 进化与生态系统

### 6.1 开放式进化规则

无内置适应度函数，不做任何人工引导与奖励。

选择压力完全来自资源有限、种间捕食、环境梯度、随机灾害。

物种定义：基因组遗传距离超过阈值即判定为新物种，自动分配谱系编号。

生态位分化：环境梯度自然催生不同耐受型物种，形成分层生态结构。

### 6.2 谱系追踪系统

每个生物携带唯一 ID 与父代 ID，全程可追溯。

系统自动构建系统发育树，记录每次物种分化节点。

物种灭绝时自动存档：存活时长、峰值种群、主要死因、核心性状特征。

### 6.3 生态统计维度

种群数据：各物种实时数量、出生数、死亡数、峰值数量。

死因统计：饥饿、被捕食、衰老、温度、中毒、酸度六类死因占比。

演化趋势：平均体型、速度、代谢率等性状随时间的变化曲线。

多样性指数：物种丰富度、均匀度、谱系多样性实时计算。

## 7. 沙盒模式专属特性

### 7.1 无限制创作

基因预算永久解锁，无点数限制。

全部细胞类型与功能默认开放，无需逐步解锁。

支持自定义基因组导入导出，跨存档共享物种。

全局参数可实时调整：基础温度、氧气背景值、营养扩散速率。

支持预设环境模板：热泉海床、浅海光照区、深海厌氧区、极端温度区。

自动定时存档，可设置保存间隔。

手动书签功能，标记关键演化节点。

分支演化：从任意存档点分叉，并行测试不同干预路径。

快照导出：保存当前瞬间的生态数据与物种基因组集。

解锁全部调试选项。

无限基因预算、无限干预资源。

显示细胞级调试信息与神经网络连接可视化。

| 培养皿总览 + 可切换图例图层 | `environment_overview`、`distribution_legend_*` | §3.3 小地图与「普通 / 热力 / 分析」视图；只做可视化叠加 |

| 环境配色与重置 | `environment_natural_plate_color`、`environment_wall_color`、`environment_color_reset` | 表现层，不改场数据 |

建议把每个预设模板定义为一份可序列化的 `EnvironmentPreset` 资源，字段包含上述 min / max / 覆盖范围 / 方向 / 昼夜 / 食物分布 / 地形种子，便于 §7.1「自定义导入导出」与 §7.3 快照复用。

**增补（2026-11-15，用户决策）**：`EnvironmentPreset` 必须包含皿级全局标量「营养密度」，并由此导出 §5.3.6 的最小自治核基础值；该值不硬编码在细胞逻辑里。它随存档 / 快照 / 回放序列化，运行时只读；局部营养场仍只影响摄能速率，不改写基础值。这样不同培养皿会自然筛选出不同的单细胞 / 多细胞策略，而不需要任何适应度引导。

**明确不采纳（需先修订 §5.3 / §6.1 才能引入）**：

- `adhesion_bias` 黏附优势（按连接数降低基础代谢 25% / 30% / 35%）——属于 Cell Lab 特有的经济规则，与 §5.3.3 的细胞内再分配口径不同。
- `substrate_radiation` 辐射突变、`substrate_tweak_mutations` 精细突变开关、`substrate_contaminate` 随机污染——v1.0 §5.4 / §6.1 已有自己的突变与开放式进化规则。
- 盐度、硝酸盐、密度、黏度、重力、动静摩擦——v1.0 §2.2 的 5 类场没有对应项；若要引入，先修订 §2.2 并同步 v2.1 的纹理打包方案。

**易混淆点**：Macro 的「基底温度 / 冻结 / 观察 / 培养 / 慢速观察」是时间推进档位（见 §4.3.1），不是 §2.2 的温度场参数，不得合并进环境场。

## 8. Godot 技术实现方案

### 8.1 整体架构分层

```text
SandboxManager（沙盒主控）
├── EnvironmentSystem（环境场系统）
│   └── 5类环境场 + Compute Shader 扩散计算
├── OrganismSystem（生物系统）
│   ├── 多细胞发育控制器
│   ├── 分布式神经网络
│   └── 细胞物理与弹性约束
├── EvolutionSystem（进化系统）
│   ├── 基因组编解码
│   ├── 突变算子集
│   └── 谱系与物种管理
├── InteractionSystem（交互系统）
│   ├── 10类干预工具
│   └── 视图缩放平移
├── ObservationSystem（观测系统）
│   ├── 统计面板与图表
│   ├── 生态报告生成
│   └── 谱系树可视化
└── UIManager（界面系统）
    ├── 生命设计器
    ├── 主模拟界面
    └── 生态报告面板
```

### 8.2 性能优化方案

空间分区网格：所有细胞按位置归档，碰撞、感知、交互仅检索相邻网格，复杂度 O(n)。

LOD 分级模拟：宏观视图简化为种群统计，显微视图才启用全精度细胞物理与神经计算。

对象池机制：细胞、粒子、生物实体全部复用，避免频繁 GC。

GPU 加速：环境场扩散、粒子物理、批量神经网络更新通过 Compute Shader 实现。

多线程更新：生物逻辑放入 WorkerThreadPool，与渲染线程完全解耦。

### 8.3 核心数据结构

基因组：紧凑二进制格式，支持快速复制、突变与序列化。

环境场：2D 纹理数组，GPU 读写，每帧更新扩散。

生物数据：结构体数组（SoA）布局，便于批量处理与 GPU 上传。

空间网格：固定尺寸二维数组，每个格子存储细胞索引列表。
