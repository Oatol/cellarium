## 1. 复刻口径

用户明确的复刻对象是：**Cell Lab 的多细胞设计，以及不同细胞类型组成多细胞个体后互相协作的设计理念**。

因此本文不复刻 40 Gene 槽分化树的字节布局、95 个突变算子、Java 序列化存档或 Android UI；只抽炼「一堆分化的细胞如何成为一个有功能的整体」的规则，并给出在现有 Godot 架构内的落地方案。版权边界沿用报告 §10.7：只借鉴概念，不复制源码、shader、图片或文案。

## 2. 核心判断：Cell Lab 的「个体」是涌现的，不是对象

这是本轮最重要的结论，直接决定复刻方式。

| 证据 | 结果 |
|---|---|
| `search_android_classes("Organism")` 官方 284 类 | 0 命中 |
| `search_android_classes("Group")` | 0 命中 |
| `search_android_classes("Colony")` | 0 命中 |
| `search_android_classes("Link")` | 唯一命中 `com.saterskog.cell_lab.Link` |
| `Cell` 字段 | `H[] : Link[]`、`C : int`（每细胞自己的连接表与连接数） |
| `CellWorld` 字段 | `x[] : Cell[]`（唯一一级实体数组），`Link[20]` 只是共享暂存 |

**结论**：Cell Lab 的模拟世界里只有 `Cell` 是一级实体，没有 `Organism` / `Body` / `Colony`。所谓「多细胞个体」是 `Link` 构成的**连接图连通分量**：一簇因分裂黏附和接触黏附连在一起的细胞，通过物质交换、信号和力学协同，表现得像一个个体。个体边界是规则的结果，不是显式 ID。

对照本项目 v2.1 设计文档：

| 维度 | Cell Lab（涌现式） | 本项目 v2.1（规约式） |
|---|---|---|
| 个体 | 无对象，连通分量 | 显式 `Organism`，有 ID / 谱系 / 物种 / 生死 |
| 形态生成 | 每次分裂由局部角度与黏附规则现算 | `GNP1` 内的发育程序 `DIVIDE/DIFFERENTIATE/LINK` 指令流预先编排 |
| 细胞归属 | 无，靠连接推导 | `cell_org_id` 显式标注 |
| 连接 | 运行期动态建立/拉断，双向挂载 | 发育期建立，弹性连接 + 静息长度 |
| 能量 | 每细胞独立 `w`，沿连接流动 | 个体级能量池 `energy` |
| 类型分化 | 分裂时切到 `Gene.i/Gene.j` 两个子槽 | `DIFFERENTIATE` 指令指定类型 ID |

**复刻的含义**：要抄的是 Cell Lab 那套「局部规则生成形态 + 类型分工 + 连接内经济」的**机制**，不是把项目已有的显式个体删掉改成涌现式（那会毁掉谱系、物种判定、统计快照与 Agent 接口）。正确做法是**保留显式个体作为记账与身份边界，把 Cell Lab 的局部规则注入发育程序与 tick 阶段**。

Macro 的旁证：`AdhesinLink` 是独立命名类，官方只有混淆名 `Link`；其字段与官方 `Link` 几乎同构（int 对端索引 + boolean + 3 double + 6 float），另加 3 个 boolean 与重置/参数设置方法。Mod 把黏附连接提升为语义化一等公民，恰好印证「连接才是多细胞的骨架」。

## 3. 六条协作机制（逐条附反编译证据）

### 3.1 黏附连接：个体的物理骨架

`Link` 字段（由 `<init>()`、`a(Link)` 复制方法与写入点交叉确认）：

| 字段 | 语义 | 证据 |
|---|---|---|
| `a` | 对端 `Cell[]` 下标；`-1` 表示皿壁锚点或空槽 | 构造初值 `-1`；`d(int)` 中 `link.a == -1` 走皿壁分支 |
| `b` | **true = 分裂产生的先天黏附；false = 接触产生的后天黏附** | 构造默认 `true`；`e(double)` 建母子连接时置 `true`；`d(int)` 的 GLUEOCYTE 与皿壁锚定置 `false` |
| `c` / `d` | 连接点相对**本细胞朝向** / **对端朝向**的角度 | `e(double)` 用 `d7 - cell.k` 与 `π + d7 - cell2.k` 分别写入 |
| `e` / `f` | 皿壁锚点的世界坐标 | `d(int)` 皿壁分支写入 `(k + 0.4r) * pos/|pos|` |
| `g..j` | 两端接触点渲染坐标（膜压平用） | `d(int)` 每 tick 按 `(r - Cell.a)*0.8` 重算 |
| `k` | 连接刚度 | 分裂黏附取 `Gene.h`；接触黏附固定 `0.5` |
| `l` | 连接附加长度 | 分裂黏附取 `cell.a(5)`（第 5 号调制器输出）；接触黏附 `0` |

三条建立路径：

1. **分裂黏附**（`e(double)`，`Gene.l` 为真）：母子之间新建双向 Link，双方 `C` 各 +1。这是个体得以生长的根本原因。
2. **接触黏附**（`d(int)`）：任一方是 `GLUEOCYTE` 且自身 `C < 5`、双方 `C < 20`、双方年龄 `>= 0.1`、未重复连接、且无 `KERATINOCYTE` 屏蔽时建立；角度由 `atan2` 现算。
3. **皿壁锚定**（`d(int)`）：`GLUEOCYTE` 可把 `a = -1` 的 Link 固定到培养皿边界上，让整个细胞簇附着在壁上。

拉断：`d(int)` 中两端锚点距离平方超过 `(max(r_i,r_j)*2)^2` 时，双方各自用「末尾元素填补空位」交换删除该 Link。每细胞连接硬上限 **20**（溢出会写断言日志）。

### 3.2 分裂即分化：类型布局由基因组决定

`e(double)` 的分裂触发条件（全部要满足）：

`能量 > Gene.b` 且 `年龄 > 0.5` 且 **`连接数 P <= Gene.u[9]`** 且 `浓度 p > 0.2` 且 未标记死亡 且 类型 ≠ `GAMETE` 且 对象池有空位。

注意 `u[9]` 的上界是 `w[9] = 20`，即 **Max connections 是分裂的抑制条件**——个体长到一定连接密度就停止增殖，这是 Cell Lab 控制个体规模的主要手段。

分裂动作（按顺序）：

- `cell2.a(cell)` 完整复制母细胞状态，含 `H[]` 连接表；随后把母细胞原有连接从所有对端的 `H[]` 中解除，并暂存在共享 `J[20]`。
- 按 `Gene.d`（分裂轴）与 `Gene.c`（质量比）分开位置与能量；信号 `U[0..3]`、`X/Y` 按同比例分配并各加 `1e-4` 本底，`p` 各半、年龄归零。
- **`cell.D = Gene.i`、`cell2.D = Gene.j`**：母与子分别切换到分化树的两个子槽。**同一个基因组的 40 个槽，不同槽可以是不同类型**——这就是「不同细胞类型组成同一个体」的实现：类型不是每个细胞随机选的，而是谱系位置决定的。
- `Gene.m` / `Gene.n`：把旧连接按分裂轴的几何位置重新分配给母/子（点积 `> 0.2` 归子、`< -0.2` 归母、中间取极值索引），并双向重建 Link、换算到各自新朝向。这保证分裂后个体不会散架。
- `Gene.q` / `Gene.r`：母子各自的镜像标志，产生左右不对称形态。
- `Gene.e` / `Gene.f`：子代朝向角。
- 端粒 `T` 母子同时 `-1`，`<= 0` 时双方标记死亡；`T = -1` 表示无限。
- `FLAGELLOCYTE` 形态校验：若存在 `cos(连接角) < -0.8` 的后向连接，直接判死——推进细胞不能长在个体后方。

### 3.3 形态是局部规则算出来的，不是模板

连接角度 `c/d`、分裂角 `d/e/f`、附加长度 `l`、刚度 `k` 全部来自基因参数；`d(int)` 每 tick 用这些角度重算锚点、施加弹簧-阻尼力与扭矩（约化质量 `25*w_i*w_j/(w_i+w_j)`，再按双方连接数较大者分摊），`MYOCYTE` 还会主动收缩连接长度并改变连接角，从而驱动整个个体形变。**没有一个地方存「这个个体长什么样」**，形态每次由基因组 + 物理迭代现算。

这与本项目 §4.4 发育程序「突变作用于指令本身，从而改变形态而非只改数值」是同一个理念，只是本项目用 u32 指令流、Cell Lab 用 40 槽分化树。

### 3.4 连接内经济：协作的能量学

`g(double)` 里每条连接做一次结算（保留原始符号）：

`m_i = cell.a()`：`LIPOCYTE` 为 `(w + S) * 0.36 / 2.16`，其余为 `w`（`S` 是脂肪储能）。
`r_i = Gene.g`（传递率）；若 `Gene.b > 0.36` 且 `m_i > 0.3456`，`r_i = 0`（接近分裂阈值时停止外供）；若 `Gene.o` 为真且 `w < 0.0936`，`r_i += 462.96 * (0.0936 - w)`（饥饿时提高抽取能力）。

对每条连接 `(i, j)`：

| 量 | 公式 | 限幅 |
|---|---|---|
| 净能量流 | `flow = r_j * m_i - r_i * m_j`；`Q_i -= flow * dt` | `±0.1` |
| 浓度扩散 | `R_i -= clamp(p_i - p_j, -0.6, 0.6) * dt` | `±0.6` |
| 刺激量交换 | `Z_i += (X_j - X_i) * 3 * dt` | — |

**这是双向加权流量差，不是简单扩散**：`r_j * m_i` 是对方按我的规模抽走，`r_i * m_j` 是我按对方规模抽走。于是不同 `Gene.g` 的细胞之间会形成**定向能量流**——光合/摄食型细胞可以供养运动/感知型细胞，饥饿细胞通过 `Gene.o` 主动提高抽取率。这就是「分工协作」在数值上的全部含义。

配套：`LIPOCYTE` 把超过 `0.36` 的能量存入 `S`（上限 `1.8`）供后续取用，并在信号积分里对连接的非脂肪邻居做扩散；`DEVOROCYTE` 接触时按 `0.72*dt` 直接转移能量/浓度/`X`；`NITROCYTE` 把浓度钉在 `1.0`。

### 3.5 信号协同

4 通道私有信号的完整链路见报告 §12，此处只记它在多细胞协作里的角色：信号只沿**连接**、**接触**、**分裂继承**三种离散事件传播，没有全局浓度场。因此「个体内通讯」天然被限定在连通分量内——这恰好让涌现出的细胞簇成为一个信息共同体。`NEUROCYTE` 每子步按 `Gene.u[5..8]` 路由 4 个输出到通道，`SECROCYTE` 的 `u[4]` 可刺激目标、加速生长、切断连接、增减指定通道，`SENSEOCYTE`/`STEREOCYTE` 把感知结果写进输入和。

### 3.6 类型分工与互相保护

按 `g(double)` 的类型 `switch` 与 `d(int)` 的交互分支归纳，18 种官方类型可归为六类角色（这是从方法体读出的事实分组，不是 Wiki 词条猜测）：

| 角色 | 类型 | 对个体的贡献 |
|---|---|---|
| 结构 / 黏附 | `GLUEOCYTE`、`KERATINOCYTE` | 前者建立连接（自身上限 5）并锚定皿壁；后者提供屏蔽 |
| 运动 / 形变 | `FLAGELLOCYTE`、`CILIOCYTE`、`MYOCYTE`、`BUOYOCYTE` | 推进、纤毛推力、收缩连接驱动形变、浮力调节 |
| 能量 | `PHOTOCYTE`、`DEVOROCYTE`、`LIPOCYTE`、`PHAGOCYTE` | 光合产能、接触抽取、储能缓冲、基础异养 |
| 信息 | `SENSEOCYTE`、`STEREOCYTE`、`NEUROCYTE`、`SECROCYTE` | 感知、方向感知、输出路由、分泌与调控 |
| 稳态 | `NITROCYTE` | 固定浓度 |
| 生殖 / 遗传 | `STEMOCYTE`、`GAMETE`、`VIROCYTE` | 按阈值切分化槽、受精、向宿主注入 7 个 Gene 槽 |

**互相保护的实证**：`d(int)` 在 `VIROCYTE` 注入、`DEVOROCYTE` 抽取、`SECROCYTE` 分泌、以及新建黏附之前，都会检查「自身或任一已连接邻居是否为 `KERATINOCYTE`」，是则整个交互被屏蔽。也就是说**一个角质细胞能保护它连接的整簇细胞**——这是最直白的「细胞协作产生个体级属性」。

另一个：`MYOCYTE` 的收缩量由 `cell.a(2..4)` 三个行为调制器给出，而这三个调制器可以被 `NEUROCYTE` 的输出通道驱动；`SECROCYTE` 的 `u[4]==3` 能主动切断目标全部连接（含皿壁锚点），即**主动解体**。

### 3.7 个体边界如何维持与消散

| 机制 | 位置 |
|---|---|
| 每细胞连接上限 20、GLUEOCYTE 上限 5 | `d(int)`、`e(double)` |
| 连接数抑制分裂（`P <= Gene.u[9]`） | `e(double)` |
| 端粒 `T ∈ {-1,5,10,20,40,80}` 限制分裂次数，母子同时递减 | `e(double)`、`Gene.B[6]` |
| 距离超限自动拉断，双向解除 | `d(int)` |
| 死亡交换删除时把末尾细胞的连接索引重映射到被删位置 | `a(int,boolean)` |
| `SECROCYTE` 主动切断连接、`GLUEOCYTE` 重新锚定 | `d(int)` |

`Genome.gd` 需按 v2.1 §3.2 从当前 12 字节简化实现升级为「定长头 + 变长 `dev_program[]` + checksum」完整格式，用 `version` 分派，**不另建独立发育程序资源**（避免双真相源）。`Organism` 增加 `var body: MulticellularBody`。旧存档按 `version` 读到无 `dev_program` / 无 `body` 时，退化为「1 个细胞的个体」，保证向后兼容。

### P2 tick 阶段（单写者，CommandBus 不变）

在 `TickEngine` 现有 11 阶段内插入子阶段，不新增 Autoload、不改阶段编号语义：

| 子阶段 | 职责 | 对应 Cell Lab |
|---|---|---|
| 发育（`ZYGOTE/DEVELOPING`） | 执行 `DIVIDE` / `DIFFERENTIATE` / `LINK`，角度与质量比来自发育指令；写 `CellArray` | `e(double)` |
| 连接求解 | 弹簧-阻尼 + 角度弹性 + 拉断（交换删除并双向解除） | `d(int)` 前半 |
| 角色代谢 | 按 `cell_type` 分派产能/耗能，先写各细胞 `energy` | `g(double)` 的 switch |
| **细胞内再分配** | 沿连接按加权流量差结算，守恒由「先合计再分配」保证 | `g(double)` 连接循环 |
| 接触交互 | 同个体内细胞跳过自碰撞（§4.5 已有规则），跨个体才做排斥/交互 | 空间哈希 |
| 死亡回收 | 细胞死亡时重映射对端连接；个体所有细胞死亡才回收 `Organism` | `a(int,boolean)` |

**写者约束**：`CellArray` 的扩容/回收只在阶段 11 主线程；发育指令与连接变更由 tick 内单写者执行，UI / Agent / 回放仍只 `enqueue_command`。化学信号子系统（报告 §12.7）作为**独立旁路**挂在同一 tick 的感知与积分阶段，不进 `CellArray`、不进网络权重。

## 7. 证据边界

- 全部结论来自静态反编译，APK 未执行，不证明设备运行时行为；`e(double)` / `g(double)` 存在 JADX `Code duplicated` 与 switch case 顺序警告，部分分支形态是按相邻分支推断。
- `Link` 的 `e/f` 与 `g..j` 语义按写入点与渲染缓冲分配模式推定，未追踪 OpenGL 绘制调用。
- `Gene.l/m/n/o/q/r` 的语义由 `e(double)` / `g(double)` / 突变 case 9/10/11/14/18/19 交叉确认，**未**逐个追溯到 UI 词条；本文用功能描述而非 Wiki 名称。
- Macro `AdhesinLink` 只确认类结构与字段增量，其新增 3 个 boolean 的语义未逐方法验证。
- `Cell.a(): double` 已确认为有效能量（脂肪细胞折算储能），这是连接流量公式的基础。
- `CellWorld` 中 `h(dt)` / `i()` / `c(dt)` / `h()` 四个阶段仍未读取；`Environment` 约 14 个 double 语义未还原。
- 本轮未改任何 Godot 运行时代码，也未新增实现文件。
